1. HTML Fundamentals & Semantic Structure

Penjelasan Komponen HTML:

  • <!DOCTYPE html>: Memberitahu browser bahwa dokumen ini berformat HTML5.
  • <html>: Elemen paling luar yang mencakup seluruh halaman web.
  • <head>: Berisi judul halaman (<title>) dan tautan CSS/CDN.
  • <body>: Tempat seluruh konten utama (teks, gambar, form, tabel) berada.
  • Semantic HTML: Tag khusus seperti <header>, <main>, dan <footer> yang memperjelas struktur web.
<!DOCTYPE html>
<html lang="id">
<head>
  <title>Judul Website</title>
</head>
<body>
  <header><h1>Header Website</h1></header>
  <main><p>Konten utama</p></main>
</body>
</html>

2. Penguasaan Elemen Form HTML

Elemen Form yang Diuji:

  • <form>: Wadah untuk menampung seluruh input pendaftaran.
  • <label>: Label teks penunjuk nama kolom input.
  • <input type="text" / "tel">: Input baris tunggal untuk teks / nomor HP.
  • <select> & <option>: Dropdown pilihan kategori.
  • <input type="radio">: Tombol pilihan bulat untuk partisipasi.
  • <textarea>: Input teks multibaris untuk deskripsi.
  • placeholder: Petunjuk opsional transparan di dalam kolom.
<form>
  <label>Nama Tim</label>
  <input type="text" placeholder="Nama tim...">

  <label>Kategori</label>
  <select>
    <option>Web Development</option>
  </select>

  <input type="radio" name="tipe"> Kelompok
  <button type="submit">Kirim</button>
</form>

3. Struktur HTML Table

Komponen Utama Tabel:

  • <table>: Pembungkus tabel data.
  • <thead>: Bagian baris judul kolom.
  • <tbody>: Bagian isi baris data.
  • <tr>: Baris tabel (Table Row).
  • <th>: Sel judul (Table Header - Teks Tebal).
  • <td>: Sel data biasa (Table Data).
<table>
  <thead>
    <tr><th>No</th><th>Nama Tim</th></tr>
  </thead>
  <tbody>
    <tr><td>1</td><td>CyberTeam</td></tr>
  </tbody>
</table>

5. Alur Git & GitHub Push

Perintah utama di Terminal / Git Bash untuk menyimpan dan mendeploy file proyek ke GitHub:

Langkah 1 git add .

Menandai seluruh perubahan file untuk masuk ke staging area.

Langkah 2 git commit -m "pesan"

Menyimpan riwayat revisi proyek ke dalam repository lokal.

Langkah 3 git push -u origin main

Mengirimkan commit lokal ke cloud repository GitHub.

Panduan Praktik Git Push di Terminal:

  1. Buka VS Code atau Git Bash pada folder proyek tempat file index.html disimpan.
  2. Jalankan git status untuk mengecek file yang telah diubah.
  3. Jalankan git add . untuk memasukkan semua file ke staging.
  4. Jalankan git commit -m "Update modul ICT dan tampilan website".
  5. Jalankan git push -u origin main untuk mengunggah proyek ke GitHub.
